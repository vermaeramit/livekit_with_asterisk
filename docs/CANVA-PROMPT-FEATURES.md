Using Canva, create a 1920 x 1080 presentation slide: a detailed feature
overview of an AI voice calling platform, laid out as a flow across the top and
a grid of feature panels beneath it.

STYLE
Near-white background with a very subtle cool tint. Deep indigo as the primary
colour, warm orange used only for the decision shape, teal only for the start
and end of the flow. Rounded rectangles, thin borders, soft shadows, thin
arrows with small arrowheads. Clean sans-serif: bold for headings, regular and
one size smaller for the bullet lines, in grey. Small indigo line icons.
Generous spacing. Corporate, calm, uncluttered. No photographs, no clip-art
people, no gradients.
